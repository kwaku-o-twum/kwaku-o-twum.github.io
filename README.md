# Kwaku Owusu Twum — portfolio website

Live website: https://kwaku-o-twum.github.io/

An original personal portfolio covering geospatial research, environmental governance, climate risk and digital agriculture. Includes four project case studies, selected publications, professional experience, education, contact details, and downloadable portfolio/CV PDFs.

## Edit the website

The current site is static HTML, CSS, JavaScript and SVG. No build or package installation is required.

- `index.html`: homepage, project catalogue, publications, biography and contact.
- `projects/`: detailed case studies.
- `site.css` and `site.js`: shared styles, mobile menu and project filters.
- `assets/`: images and original explanatory illustrations.
- `downloads/`: the portfolio and CV PDFs.

GitHub Pages publishes the root of the `master` branch. `.nojekyll` serves the static files without the previous Jekyll build.

## Previous website

The previous AcademicPages version is preserved in the `backup-before-portfolio-2026-11-21` branch. Legacy template source is retained in this repository; the active portfolio is the static site listed above.
